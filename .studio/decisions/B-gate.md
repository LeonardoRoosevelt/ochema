# 門禁 B 使用者裁決（2026-11-09）

- 設計方向：ledger（帳冊）。
- DBML：核可（vehicle_records；四欄複合 unique；三個單欄索引）。待 A 重新核可後一併 approve B。
- 範圍變更（使用者主動提出）：匯入也要支援舊式 .xls 與 CSV。
  - CSV 只支援 UTF-8（含／不含 BOM）。
  - 匯出提供 .xlsx、.xls、CSV 三種可選。
- 製片人決定：
  - 非 UTF-8（例如 Big5）的 CSV → 「無法讀取」，並提示以「CSV UTF-8」另存；不匯入亂碼。
  - 格式判定依內容：PK 開頭→.xlsx；D0 CF 11 E0 開頭→.xls；其他且為合法 UTF-8 文字、無 NUL 位元組→CSV；否則無法讀取（隨機二進位資料情境維持「無法讀取」）。
  - CSV 匯出用 UTF-8＋BOM（Excel 開啟中文不亂碼）；所有格式值皆為原字串。
  - 製片人取代先前「只收 .xlsx」的已知限制。

## 製片人裁決（產品部 formats 待決）
1. 畫面預設匯出格式 .xlsx。
2. 只有 BOM 的 CSV → 檔案是空的。
3. CSV 引號內含換行依 RFC 4180 支援（不另寫情境）。
4. CSV 某列欄位少於標題 → 缺的視為空白（必填則格式錯誤）；多出的欄位忽略，與 .xlsx 一致。
5. 判定順序：長度 0 → 檔案是空的；再依內容判定格式。
6. 副檔名與內容不符時依內容讀取。
