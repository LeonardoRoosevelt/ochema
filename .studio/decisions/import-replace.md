# 使用者裁決：匯入改為整份替換（2026-11-09，交付後變更）

1. 匯入＝整份替換：確認後清空現有名單，寫入檔案內容（不再累計）。
2. 檔案有任何格式錯誤列（車牌格式、必填空白…）→ 整份擋下、不可確認、不替換；預覽列出錯誤列與原因。
3. 檔內重複：同車頭車號、同車斗車號、同駕駛身分證不同姓名照樣匯入，替換後在名單與總覽持續標示；四欄完全相同的列只保留第一筆（預覽告知哪些列被合併）。移除「略過重複／照樣匯入」選項；不再有「與既有資料重複」分類。
4. 保護：預覽寫明「將刪除目前 N 筆、匯入 M 筆」；按確認後再跳確認框（預設焦點「取消」），框內提供「先匯出目前資料」（匯出全部，預設 .xlsx）。取消則名單不變。
5. 手動新增、編輯、刪除保留。
6. 製片人決定：空檔、只有標題列、無法讀取、缺標題、非 UTF-8 CSV → 擋下、不替換（沿用既有拒收行為）。身分證警示列照常匯入。替換為單一交易，失敗則名單維持原狀。
